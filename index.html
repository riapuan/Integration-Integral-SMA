Uji Kompetensi Integral Tak Tentu

Mata Pelajaran Matematika Kelas 11 •

Tier 1: Dasar (Hutan Logika)
Soal 1 (Pilihan Ganda)
Hasil dari integral tak tentu \(\int 6x^2 \, dx\) adalah...
Pembahasan
Gunakan rumus dasar \(\int a x^n dx = \frac{a}{n+1}x^{n+1} + C\).
\(\int 6x^2 \, dx = \frac{6}{2+1}x^{2+1} + C = \frac{6}{3}x^3 + C = 2x^3 + C\).
Soal 2 (Pilihan Ganda)
Nilai dari \(\int 5 \, dx\) adalah...
Pembahasan
Integral dari konstanta \(k\) adalah \(\int k \, dx = kx + C\). Maka \(\int 5 \, dx = 5x + C\).
Soal 3 (Pilihan Ganda)
Hasil dari \(\int (4x^3 - 2x) \, dx\) adalah...
Pembahasan
\(\int (4x^3 - 2x) \, dx = \frac{4}{4}x^4 - \frac{2}{2}x^2 + C = x^4 - x^2 + C\).
Soal 4 (Pilihan Ganda)
Tentukan hasil dari \(\int 12x^3 \, dx\).
Pembahasan
\(\int 12x^3 \, dx = \frac{12}{3+1}x^{3+1} + C = \frac{12}{4}x^4 + C = 3x^4 + C\).
Soal 5 (Pilihan Ganda)
Bentuk integral dari \(\int \frac{1}{x^2} \, dx\) sama dengan...
Pembahasan
Ubah ke bentuk pangkat: \(\int x^{-2} \, dx = \frac{1}{-2+1}x^{-2+1} + C = -1x^{-1} + C = -\frac{1}{x} + C\).
Soal 6 (Isian Singkat)
Tentukan hasil dari \(\int 10x^4 \, dx\). (Tuliskan tanpa spasi atau format standar, misal: 2x^5+C)
Pembahasan
\(\int 10x^4 \, dx = \frac{10}{5}x^5 + C = 2x^5 + C\).
Soal 7 (Isian Singkat)
Hasil dari \(\int (8x - 3) \, dx\) adalah...
Pembahasan
\(\int 8x \, dx - \int 3 \, dx = \frac{8}{2}x^2 - 3x + C = 4x^2 - 3x + C\).
Soal 8 (Isian Singkat)
Tentukan nilai integral dari \(\int 3\sqrt{x} \, dx\).
Pembahasan
\(\int 3x^{\frac{1}{2}} \, dx = \frac{3}{\frac{3}{2}}x^{\frac{3}{2}} + C = 2x^{\frac{3}{2}} + C = 2x\sqrt{x} + C\).
Soal 9 (Isian Singkat)
Hasil dari \(\int (-6x^{-3}) \, dx\) adalah...
Pembahasan
\(\int -6x^{-3} \, dx = \frac{-6}{-3+1}x^{-3+1} + C = \frac{-6}{-2}x^{-2} + C = 3x^{-2} + C\).
Soal 10 (Isian Singkat)
Tentukan nilai integral dari \(\int (9x^2 + 4x - 5) \, dx\).
Pembahasan
Integralkan setiap suku: \(\frac{9}{3}x^3 + \frac{4}{2}x^2 - 5x + C = 3x^3 + 2x^2 - 5x + C\).
Tier 2: Lanjut (Laboratorium Rumus)
Soal 11 (Pilihan Ganda)
Hasil dari \(\int (2x - 3)(x + 1) \, dx\) adalah...
Pembahasan
Jabarkan terlebih dahulu: \((2x - 3)(x + 1) = 2x^2 + 2x - 3x - 3 = 2x^2 - x - 3\).
Integralkan: \(\frac{2}{3}x^3 - \frac{1}{2}x^2 - 3x + C\).
Soal 12 (Pilihan Ganda)
Diketahui \(f'(x) = 6x^2 - 4x + 5\) dan \(f(1) = 4\). Nilai \(f(x)\) adalah...
Pembahasan
\(f(x) = \int (6x^2 - 4x + 5) \, dx = 2x^3 - 2x^2 + 5x + C\).
Masukkan \(f(1) = 4 \Rightarrow 2(1) - 2(1) + 5(1) + C = 4 \Rightarrow 5 + C = 4 \Rightarrow C = -1\).
Maka \(f(x) = 2x^3 - 2x^2 + 5x - 1\).
Soal 13 (Pilihan Ganda)
Hasil dari \(\int \frac{3x^4 - 6x^2}{x^2} \, dx\) adalah...
Pembahasan
Sederhanakan bentuk aljabarnya: \(\int (3x^2 - 6) \, dx = x^3 - 6x + C\).
Soal 14 (Pilihan Ganda)
Hasil dari integral \(\int 3x(x^2 - 4)^4 \, dx\) menggunakan metode substitusi adalah...
Pembahasan
Misalkan \(u = x^2 - 4\), maka \(du = 2x \, dx \implies x \, dx = \frac{1}{2} du\).
\(\int 3u^4 \left(\frac{1}{2} du\right) = \frac{3}{2} \cdot \frac{1}{5} u^5 + C = \frac{3}{10}(x^2 - 4)^5 + C\).
Soal 15 (Pilihan Ganda)
Tentukan hasil dari \(\int (x + 2)^2 \, dx\).
Pembahasan
Dengan substitusi \(u = x+2\) dan \(du = dx\), maka \(\int u^2 du = \frac{1}{3}u^3 + C = \frac{1}{3}(x+2)^3 + C\).
Soal 16 (Isian Singkat)
Jika \(f'(x) = 3x^2 + 2x - 1\) dan \(f(2) = 10\), tentukan nilai konstanta \(C\) dari \(f(x)\).
Pembahasan
\(f(x) = x^3 + x^2 - x + C\).
\(f(2) = 2^3 + 2^2 - 2 + C = 8 + 4 - 2 + C = 10 \implies 10 + C = 10 \implies C = -6\).
Soal 17 (Isian Singkat)
Tentukan hasil dari \(\int 4x(x^2 + 3)^3 \, dx\).
Pembahasan
Misal \(u = x^2+3, du = 2x dx\). Integral menjadi \(\int 4u^3 (\frac{1}{2}du) = \int 2u^3 du = \frac{1}{2}(4)u^4 + C = (x^2+3)^4 + C\).
Soal 18 (Isian Singkat)
Hasil dari \(\int \frac{6x^2}{\sqrt{2x^3 + 5}} \, dx\) adalah...
Pembahasan
Misal \(u = 2x^3+5 \implies du = 6x^2 dx\). Integral \(\int u^{-1/2} du = 2u^{1/2} + C = 2\sqrt{2x^3+5} + C\).
Soal 19 (Isian Singkat)
Tentukan hasil dari \(\int (x - 1)^3 \, dx\).
Pembahasan
Dengan substitusi langsung \(u = x-1\), didapat \(\frac{1}{4}(x-1)^4 + C\).
Soal 20 (Isian Singkat)
Jika diketahui \(f''(x) = 12x - 2\), \(f'(0) = 5\), dan \(f(0) = 3\), tentukan nilai dari \(f(1)\).
Pembahasan
\(f'(x) = \int (12x - 2) dx = 6x^2 - 2x + C_1\). Karena \(f'(0) = 5\), maka \(C_1 = 5\).
\(f(x) = \int (6x^2 - 2x + 5) dx = 2x^3 - x^2 + 5x + C_2\). Karena \(f(0) = 3\), maka \(C_2 = 3\).
\(f(1) = 2(1)^3 - (1)^2 + 5(1) + 3 = 2 - 1 + 5 + 3 = 9\). (Wait, \(2-1+5+3 = 9\)). Jawaban: 9.
Tier 3: HOTS (Kota Pemikiran Kritis)
Soal 21 (Pilihan Ganda)
Kecepatan suatu benda bergerak dinyatakan oleh fungsi \(v(t) = 3t^2 - 4t + 5\) (dalam m/s). Jika pada saat \(t = 1\) detik posisi benda berada di \(s(1) = 10\) meter, tentukan fungsi posisi \(s(t)\) benda tersebut.
Pembahasan
\(s(t) = \int v(t) \, dt = \int (3t^2 - 4t + 5) \, dt = t^3 - 2t^2 + 5t + C\).
\(s(1) = 1^3 - 2(1)^2 + 5(1) + C = 10 \implies 1 - 2 + 5 + C = 10 \implies 4 + C = 10 \implies C = 6\).
Maka \(s(t) = t^3 - 2t^2 + 5t + 6\).
Soal 22 (Pilihan Ganda)
Biaya marginal produksi suatu barang per unit dinyatakan sebagai \(MC = 6x - 12\) (dalam ribuan rupiah). Jika biaya tetap (fixed cost) adalah Rp50.000,00, fungsi total biaya \(TC\) untuk memproduksi \(x\) unit adalah...
Pembahasan
\(TC = \int MC \, dx = \int (6x - 12) \, dx = 3x^2 - 12x + C\).
Biaya tetap adalah biaya saat \(x = 0\), yaitu \(TC(0) = 50\) (dalam ribuan). Maka \(C = 50\).
\(TC = 3x^2 - 12x + 50\).

Soal 24 (Pilihan Ganda)
Suatu kurva melalui titik \((1, 4)\) dan memiliki gradien garis singgung di setiap titik \((x, y)\) sebesar \(f'(x) = 3x^2 - 2\). Persamaan kurva tersebut adalah...
Pembahasan
\(y = \int (3x^2 - 2) \, dx = x^3 - 2x + C\). Melalui \((1, 4)\):
\(4 = 1^3 - 2(1) + C \implies 4 = 1 - 2 + C \implies 4 = -1 + C \implies C = 5\).
Maka \(y = x^3 - 2x + 5\).
Soal 25 (Pilihan Ganda)
Sebuah pabrik memproduksi mainan dengan biaya marginal \(MC = 100 - 4x\). Jika biaya tetapnya adalah 2000, berapa total biaya untuk memproduksi 10 unit mainan?
Pembahasan
\(TC = \int (100 - 4x) \, dx = 100x - 2x^2 + 2000\).
Untuk \(x = 10\): \(TC = 100(10) - 2(10)^2 + 2000 = 1000 - 200 + 2000 = 2800\).
Soal 26 (Isian Singkat)
Suatu partikel bergerak dengan percepatan \(a(t) = 6t - 2\). Kecepatan awal partikel pada \(t = 0\) adalah 4 m/s. Tentukan kecepatan partikel pada saat \(t = 3\) detik.
Pembahasan
\(v(t) = \int (6t - 2) dt = 3t^2 - 2t + C_1\). Karena \(v(0) = 4\), \(C_1 = 4\).
\(v(3) = 3(3)^2 - 2(3) + 4 = 27 - 6 + 4 = 25\). (Wait: \(27 - 6 = 21 + 4 = 25\)). Jawaban: 25.
Soal 27 (Isian Singkat)
Penerimaan marginal (marginal revenue) dari suatu perusahaan adalah \(MR = 15 - 3x\). Tentukan fungsi penerimaan total (\(TR\)) jika \(TR(0) = 0\).
Pembahasan
\(TR = \int (15 - 3x) dx = 15x - \frac{3}{2}x^2 + C\). Karena \(TR(0) = 0\), maka \(C = 0\). Jadi \(TR = 15x - \frac{3}{2}x^2\).
Soal 28 (Isian Singkat)
Sebuah benda dilempar ke atas dengan kecepatan awal \(v_0 = 20\) m/s dari ketinggian tanah (\(s(0) = 0\)). Jika percepatan gravitasi \(g = -10\) m/s\(^2\), berapakah ketinggian maksimum yang dicapai benda? (Petunjuk: \(v(t) = 0\) saat tinggi maksimum).
Pembahasan
\(v(t) = \int (-10) dt = -10t + 20\). Tinggi maksimum saat \(v(t) = 0 \implies t = 2\).
\(s(t) = \int (-10t + 20) dt = -5t^2 + 20t\).
\(s(2) = -5(2)^2 + 20(2) = -20 + 40 = 20\) meter.
Soal 29 (Isian Singkat)
Diketahui kemiringan garis singgung kurva \(f'(x) = 4x - 3\). Jika kurva melalui titik \((2, 5)\), tentukan nilai \(f(3)\).
Pembahasan
\(f(x) = \int (4x - 3) dx = 2x^2 - 3x + C\). Melalui \((2, 5)\): \(5 = 2(2)^2 - 3(2) + C \implies 5 = 8 - 6 + C \implies C = 3\).
\(f(x) = 2x^2 - 3x + 3\). Maka \(f(3) = 2(3)^2 - 3(3) + 3 = 18 - 9 + 3 = 12\).

Tier 4: Olimpiade (Ruang Angkasa Penalaran)
Soal 31 (Pilihan Ganda)
Jika \(\int f(x) \, dx = x^2 \sin x + C\), maka nilai dari \(f\left(\frac{\pi}{2}\right)\) adalah...
Pembahasan
Hubungan integral dan turunan: \(f(x) = \frac{d}{dx} \left( x^2 \sin x \right) = 2x \sin x + x^2 \cos x\).
Untuk \(x = \frac{\pi}{2}\): \(2\left(\frac{\pi}{2}\right)\sin\left(\frac{\pi}{2}\right) + \left(\frac{\pi}{2}\right)^2\cos\left(\frac{\pi}{2}\right) = \pi(1) + \frac{\pi^2}{4}(0) = \pi\).
Soal 32 (Pilihan Ganda)
Diketahui \(\int x f(x) \, dx = x^3 - 2x^2 + C\). Fungsi \(f(x)\) adalah...
Pembahasan
Turunkan kedua ruas terhadap \(x\):
\(x \cdot f(x) = \frac{d}{dx}(x^3 - 2x^2) = 3x^2 - 4x\).
\(f(x) = \frac{3x^2 - 4x}{x} = 3x - 4\).
Soal 33 (Pilihan Ganda)
Jika \(\int (f(x) + 2x) \, dx = x^3 + x^2 - 5x + C\), maka \(f(x) = \dots\)
Pembahasan
Turunkan kedua ruas terhadap \(x\):
\(f(x) + 2x = \frac{d}{dx}(x^3 + x^2 - 5x) = 3x^2 + 2x - 5\).
\(f(x) = 3x^2 + 2x - 5 - 2x = 3x^2 - 5\).
Soal 34 (Pilihan Ganda)
Bentuk integral \(\int \frac{dx}{x^2 + 2x + 1}\) dapat diselesaikan dengan menyederhanakan penyebut menjadi kuadrat sempurna. Hasilnya adalah...
Pembahasan
Penyebut \(x^2 + 2x + 1 = (x+1)^2\). Integral menjadi \(\int (x+1)^{-2} dx = -(x+1)^{-1} + C = -\frac{1}{x+1} + C\).
